# Testing and Fault Tolerance (01RKZYG) - Labs Repository

This repository contains all the projects and practical exercises developed for the **Testing and Fault Tolerance (01RKZYG)** course at Politecnico di Torino for the Academic Year 2026/27.

## Course Information
* **Lab Team:** Prof. Riccardo Cantoro, Reza Khoshzaban, Michelangelo Bartolomucci.
* **Environment:** The activities run in a Linux environment on the department's LabInf PCs.
* **Commercial EDA Tools Used:**
  * **Design Compiler:** for logic synthesis.
  * **Questa SIM:** for logic simulation.
  * **TestMAX:** for ATPG (Automatic Test Pattern Generation) and fault simulation.
  * **Z01X:** for fault simulation and fault injection.

## Laboratories List

The repository is organized into subfolders for each laboratory session:

* **[Lab 1](./lab1) — Stuck-at Faults by Hand: Fault Lists and Fault Injection by Logic Simulation**
  * *Objective:* Understanding the single stuck-at fault model through manual analysis and logic simulation. The lab focuses on the fundamental principle of testing (*Test = Control + Observe*), identifying equivalence classes, and reading a fault dictionary.
  * *Tools:* Synopsys TestMAX ATPG, Siemens Questa SIM, Synopsys Design Compiler.

*(This list will be updated as the course progresses and new labs are added).*
